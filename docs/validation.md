## Acceptance metric

On the seeded showcase, domain `mic-b`:

- Target-test split size 18 (10 labeled normal, 8 labeled anomaly).
- Change in target-normal false-alert rate: 1.0 to 0.2, delta −0.8.
- Change in target anomaly recall: 1.0 to 1.0, delta 0.0.
- Both sides meet the predeclared bounds (false alerts fall, recall drop ≤ 0.25).

On the recall-loss fixture the same source threshold still alerts 10/10 normals and 8/8 anomalies. The proposed threshold alerts 1/10 normals and 4/8 anomalies. Recall drop 0.50 exceeds 0.25, so the proposal is not accepted. Status `calibration_unsuccessful`. Scores are still shown.

## Domain safeguard

- A session that appears in two splits is rejected before fitting (`overlap` fixture).
- Target calibration must be at least 8 operator-approved normals. Three normals produce `insufficient_normals` and no proposed threshold.
- An empty `microphone_domain` is `missing_metadata`. Anomaly status is omitted.
- A `label=unknown` clip is marked uncertain, gets no alert bit, and is left out of the false-alert and recall denominators.
- File size above 1 MiB, duration outside 0.5–2.0 s, a sample rate other than 16000 Hz, more than one channel, non-16-bit PCM, an all-zero clip, and a clip with more than 1% of samples at the 16-bit rail are rejected before the spectrum step.

## Trust boundary

- Manifest paths must stay inside the manifest directory. `../` is `path_escape`.
- The report writer only creates `result.json`, `scores.csv`, `summary.html`, and `summary.txt` inside the output directory.
- HTML text from the manifest is escaped.
- There is no child process, no network call on the demo path, and no secret in the repository.
- The workflow in `.github/workflows/ci.yml` sets `contents: read` and, for the demo artifact only, `actions: write`. Actions are pinned to commit SHAs. The job does not use secrets.

## Performance budget

The supported demo is 50 clips of 1.0 s at 16 kHz. Budget: under 10 seconds on an ordinary developer machine, including process startup. Observed: 0.038 s for `machineear demo` on this host. `tests/test_safeguards.py` fails the run if it reaches 10 seconds.

## Residual limits

- The fixture is synthetic. A real microphone move can differ from a 900 Hz background tone.
- Scores are distances from a source-normal centroid. They are not a diagnosis.
- DCASE and MIMII audio are not included. The Zenodo license text for the DCASE 2023 development set disagrees with itself (CC BY-NC-SA 4.0 in the condition of use, CC BY 4.0 on the widget), so it stays out.
- Hosted GitHub Actions is checked in P07, not by this local run.
